BattleTown

Class-based PvP arenas for Minecraft Java. Pick one of 16 classes, jump into a fast match, and build your own Maps.

How to join

  1. Open Minecraft: Java Edition 26.3.
  2. Go to Multiplayer, then Add Server.
  3. Type play.battletown.store as the server address, then join.
  4. Say yes to the BattleTown resource pack. The game needs it.

What's inside

16 classes

Knights, Assassins, Frostborn, Necromancers and more. Each one has its own weapons and abilities.

4 game modes

Duel, Free For All, Team Deathmatch and Last Alive. Matches last about 4 to 7 minutes.

Maps you build

Buy a Map, build an arena in Creative, and send it to BattleTown to join public matches.

Store

BattleBucks bundles. The web store is coming soon.
